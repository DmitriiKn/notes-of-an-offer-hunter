Эта инструкция поможет вам системно и с наименьшим риском вносить масштабные изменения в кодовую базу, используя возможности Qwen Code.

---

### 1. Этап 1: Активация режима планирования (`/plan`)

Первый и самый важный шаг — перевести Qwen Code в **режим планирования (Plan Mode)**. В этом режиме AI выполняет **только операции чтения**, не изменяя код, что идеально подходит для анализа и планирования.

**Как активировать:**
*   **В активной сессии:** Используйте комбинацию клавиш `Shift+Tab` (или просто `Tab` в Windows), чтобы переключаться между режимами, пока в строке состояния не появится значок `⏸ plan mode`.
*   **При запуске новой сессии:** Выполните команду `/approval-mode` и выберите опцию `plan`, чтобы запустить сессию сразу в нужном режиме.

### 2. Этап 2: Формулировка задачи для планирования

Теперь можно приступать к постановке задачи. Максимально подробно опишите Qwen Code, что именно нужно изменить или реализовать. Хорошо описанная задача — залог точного плана.

Qwen Code самостоятельно проанализирует вашу кодовую базу и может даже инициировать веб-поиск, если задание требует знаний о новых технологиях или последних API.

**Пример запроса:**
> "Нужно рефакторить нашу систему аутентификации: перейти с сессий на JWT-токены. Проанализируй текущую реализацию (`/auth`), оцени, какие файлы (`/middleware`, `/models`, `/routes`) будут затронуты, и предложи пошаговый план миграции."

### 3. Этап 3: Получение и утверждение плана

На основе вашего запроса Qwen Code сгенерирует подробный план действий, в котором будут перечислены:
*   Конкретные файлы для изменения.
*   Необходимые изменения в логике.
*   Последовательность шагов для реализации.

Ваша задача — **внимательно проверить этот план**. Убедитесь, что AI правильно понял требования. На этом этапе вы можете уточнять детали, задавать вопросы или просить скорректировать план. Вы имеете полный контроль над процессом.

### 4. Этап 4: Переход к выполнению (`/act`) и реализация

Когда план утверждён, пора переходить к действию. Qwen Code предоставляет для этого инструмент `exit_plan_mode`.

**Как перейти к выполнению:**
AI автоматически использует этот инструмент, чтобы представить план на ваше утверждение. У вас будет три варианта ответа:
*   **"Выполнить один раз"** : Одобрить план для текущей задачи.
*   **"Всегда выполнять"** : Утвердить план и включить автоматическое одобрение для всех последующих операций.
*   **"Отмена"** : Отклонить план и остаться в режиме планирования для его доработки.

После вашего утверждения (`/act`) Qwen Code перейдёт в режим выполнения и начнёт вносить изменения в код в соответствии с утверждённым планом.

### 5. Лучшие практики для успешных правок

*   **Начинайте с «Плана»:** Всегда инициируйте масштабные задачи в этом режиме. Это предотвращает нежелательные изменения и даёт вам полный контроль.
*   **Используйте итеративный подход:** Если задача очень большая, разбейте её на несколько этапов. Сначала спланируйте и реализуйте один модуль, затем переходите к следующему.
*   **Уточняйте требования:** Не стесняйтесь задавать AI уточняющие вопросы во время фазы планирования, чтобы убедиться, что вы оба смотрите в одном направлении.

### Заключение

Использование режимов `/plan` и `/act` в Qwen Code превращает сложную задачу масштабных изменений в управляемый и безопасный процесс. Вы не просто отдаёте команду AI, а выступаете в роли архитектора, который сначала утверждает детальный план, а затем даёт добро на его реализацию. Такой подход гарантирует, что конечный результат будет соответствовать вашим ожиданиям и не нарушит работу всей системы.
